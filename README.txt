MINAMARK RESORT & SPA — STATIC WEBSITE REDESIGN

Files
- index.html: page structure and content
- style.css: responsive styling, layouts, transitions and RTL rules
- script.js: four-language switcher, mobile menu, booking popup, form validation and scroll reveals

Run
Open index.html in a browser, or upload all three files to your hosting root.
No build tools or frameworks are required.

Languages
English, Russian, German and Arabic. The selected language is remembered in localStorage.
Arabic switches the document to RTL layout.

Booking
The popup collects check-in/check-out, rooms, adults, children and an optional promo code.
On submit it redirects to MinaMark's existing booking partner at minamark.book-onlinenow.net.
Please verify the partner's expected query parameter names and booking flow before publishing.

Images and fonts
The concept uses remote Unsplash image URLs and Google Fonts. Replace these with approved MinaMark property photography before production.
All text and layout are editable directly in the HTML and JS translation dictionary.

Important
This is a front-end concept. It does not connect to a hotel PMS or create reservations itself.
Contact details and hotel location are based on the public MinaMark website.
